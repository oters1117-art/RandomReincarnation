# 랜덤 다시 태어나기

다시 태어난다면 어느 나라에서 태어날까? 전 세계 인구 비율대로 국가를 무작위로 뽑아 보여 주는 웹페이지입니다.

👉 **https://oters1117-art.github.io/RandomReincarnation/**

## 기능

- `연간 출생아` 또는 `세계 인구` 기준으로 추첨 (인구가 많은 나라일수록 잘 나옵니다)
- 뽑힌 나라의 확률, 소개, 주요 통계, 인구·출생아 수, 지도 위치 표시
- 최근 추첨 기록

## 데이터

인구·출생 데이터는 UN World Population Prospects 2024의 2026년 중위 추계를 기준으로 합니다.

## 실행

빌드 없이 `index.html` 하나로 동작합니다. 브라우저로 열면 바로 실행됩니다.
